# Canchazo

Plataforma web para reservar canchas de fútbol y pádel. Los jugadores pueden buscar canchas, aplicar filtros por deporte, precio y horario, reservar turnos, dejar reseñas y guardar favoritos. Los dueños gestionan su complejo desde un panel de administración con almanaque de reservas, control de estados de pago, reseñas y estadísticas de ingresos.

Los datos se persisten localmente en el navegador (localStorage), por lo que no requiere backend para funcionar.

## Requisitos

- Node.js

## Comandos

- `npm install` — instala las dependencias
- `npm run dev` — inicia el servidor de desarrollo en el puerto 3000
- `npm run lint` — verifica tipos con TypeScript
- `npm run build` — compila la app para producción
- `npm run preview` — previsualiza el build de producción

## Stack

React + TypeScript + Vite + Tailwind CSS 4
